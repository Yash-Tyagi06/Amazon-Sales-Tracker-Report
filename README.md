# 🛒 Amazon Sales Tracker Report – Excel & Power BI

## 📌 Project Overview
The **Amazon Sales Tracker Report** is a Data Analytics project developed using Microsoft Excel and Power BI to analyze sales performance, revenue trends, and business growth opportunities.

The project focuses on transforming raw sales data into meaningful insights through data cleaning, analysis, visualization, and interactive dashboards.

## 🎯 Project Objectives
- Analyze overall sales and revenue performance.
- Track sales trends over time.
- Identify top-performing products and categories.
- Evaluate regional sales performance.
- Discover business growth opportunities.
- Present key insights through interactive visualizations.

## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data cleaning, data analysis, Pivot Tables, and charts.
- **Microsoft Power BI** – Interactive dashboards and data visualization.
- **Power Query** – Data transformation and preprocessing.
- **DAX** – Measures and calculated metrics.

## 📊 Key Features
- Sales and revenue tracking.
- Product and category-wise performance analysis.
- Regional sales analysis.
- Interactive filters and slicers.
- KPI-based performance monitoring.
- Visual representation of sales trends.

## 📈 Key Insights
The dashboard helps users understand:
- Which products and categories generate the highest sales.
- How revenue changes over time.
- Which regions contribute most to overall sales.
- Potential areas for business improvement and growth.
